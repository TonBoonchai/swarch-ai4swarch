# สะท้อนคิดรายบุคคล (≤ 150 คำ)

**ชื่อ / รหัสนิสิต:** บุญชัย จินาพร / 6632110421
**บทบาทของฉันในคณะกรรมการ:** Site reliability engineer (SRE)

หลังจากทำส่วน A และส่วน B แล้ว นิสิตจะไว้วางใจให้ AI ทำงานส่วนใดของสถาปนิก และจะเก็บงานส่วนใดไว้ให้มนุษย์ ยกตัวอย่างที่เป็นรูปธรรมหนึ่งตัวอย่างจากการประชุมคณะกรรมการ

ผมจะไว้ใจให้ AI ช่วยวิเคราะห์ไฟล์ `.proto` สรุปโครงสร้าง API และสร้างแผนภาพเบื้องต้น แต่จะให้คนตรวจสอบ flow การทำงานจริงและบริบทของระบบก่อนเผยแพร่ เพราะ AI ไม่สามารถรู้ข้อมูลที่ไม่ได้ระบุไว้ในไฟล์ได้ เช่น จากการประชุม ทีมเคยใช้ RabbitMQ เฉพาะบนเครื่องตัวเอง ซึ่ง AI ไม่สามารถอนุมานข้อเท็จจริงนี้จาก `.proto` เพียงอย่างเดียวได้
